# 静态安全复核

本报告只针对本轮实际设备与当前修订代码。原始 /etc 备份、SSH 主机密钥、真实节点与订阅均留在私有工作区，不进入修复包。公开证据已脱敏；原始命令、输入和完整输出仍保存在本机私有证据目录。执行过程先完成探测与计划，再按轮次进行受控测试，未修改固件、分区或 Bootloader。

| 编号 | 级别 | 结论与修复 | 证据 |
|---|---|---|---|
| HW-001 | P1 | 原版无基线回滚删除已有设置，部分备份也不能恢复完整规则；改为完整快照、摘要校验、逐文件恢复验证，无快照时不修改 | REPRO-REVERT-001；FINAL2-SEED-* |
| HW-002 | P1 | 原版信任共享 /tmp PID 并以 root 杀进程；改为私有令牌撤销，不按外部 PID 杀进程 | REPRO-PID-001；FIX-PID-001 |
| HW-003 | P1 | 默认无口令 Clash API 监听所有接口，真机远程请求返回 200；默认改为回环，审计器拒绝无口令非回环监听 | REPRO-API-001；FIX-API-* |
| HW-004 | P1 | 网络 reload/回滚错误被忽略，可能假报恢复成功；改为非零失败、保留现场和持久化独立恢复，核验配置/参数/服务 | FAULT-RELOAD-*；BOOT-* |
| HW-005 | P2 | 两套引擎共享 watchdog 标记且缺少设备写锁；改为全局 flock、引擎所有者与私有状态 | FIX-CONFLICT-dae-openwrt；FAULT-LOCK-* |
| HW-006 | P2 | DNS 诊断把 FakeIP/空答案等同于零泄漏或成功阻断；改为限定观察结论，缺失答案标记警告 | DNS-001；FINAL-*-diagnose_dns.sh |
| HW-007 | P2 | 正常解析日志、节点失败可能误报配置错误；缩小错误模式，节点问题独立标记需人工核对，并注册修复契约 | FINAL2-DOCTOR-*；test_doctor_evidence |

修复过程中另发现并修正：使用 stat 会在该精简固件失败；新增诊断 ID 初次未同步修复注册表。两次失败均在交付前被实际测试发现，最终回归重新执行。未把早期失败日志当作最终通过证据。

网络恢复改为私有 0700 状态目录及 0600 文件；设备 flock 稳定文件不按 PID 杀进程；跨引擎事务互斥；快照和清单校验后才写入；恢复通过逐文件哈希、参数读回与服务进程验证。恢复代码持久化，适用于 SSH stdin 执行。检测到部署后外部配置变化时拒绝覆盖并保留快照。

旧版部分基线不能与新版混合部署。已运行裸进程无 init 服务时拒绝接管，避免无法恢复其生命周期。原有 Python SSRF 请求内 DNS 固定、逐跳重定向检查、SSH 参数引用和事务状态机保持回归覆盖；本轮未把这些宿主/仿真测试写成 R2S Python 真机测试。
