# 兼容性

| 环境/能力 | 证据等级 | 结果 |
|---|---|---|
| R2S ARM64、ImmortalWrt 25.12.2、6.12.103、fw4 | 真机 | 已测网络应用/恢复与两原生校验器 |
| sing-box 1.14.4 ARM64 musl | 真机 | 配置校验、本机 TCP 转发、API 边界通过；TUN BLOCKED |
| dae 2.1.1 ARM64 | 真机 | 校验、热重载、恢复通过；LAN 完整业务 BLOCKED |
| Alpine 3.23 x86_64、Python 3.12.16 | 独立 Linux 内核/仿真设备 | 自动回归，不能代替 OpenWrt 流量测试 |
| Windows、Python 3.13.11 | 宿主 | 自动回归，Linux 专属分支跳过 |
| OpenWrt 18/19/21 fw3、其他固件、MIPS/ARMv7 | 静态/未测试 | 不保证真机兼容 |
| IPv6 公网双栈、TProxy | 未测试/环境阻塞 | 不支持通过结论 |

本机缺 stat 的兼容性问题在修复早期被发现并移除依赖。网络接管现在显式要求 flock 等工具；缺失时应失败关闭，不把“代码有分支”当作兼容证明。软件源不可用时没有强行换用异版内核包。
