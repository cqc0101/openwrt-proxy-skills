# 恢复结论

| 对象/故障 | 结论 | 边界 |
|---|---|---|
| 配置、DNS 设置、防火墙配置 | PASS | 全部 /etc 普通文件最终逐个 SHA-256 与归档一致 |
| 七项受管 sysctl 参数 | PASS | 每次事务快照内读回验证；不等于所有内核参数穷尽 |
| dae 服务状态 | PASS | 进程、原始配置及原生校验；外网完整业务未证明 |
| SSH 中断 | PASS | 关闭控制 SSH 后 45 秒计时器独立恢复 |
| 设备重启 | PASS | 实际 reboot、boot ID 改变、原始配置恢复、快照清理 |
| 回滚依赖自身失败 | PASS（检测） | 返回失败并保留快照，依赖修好后重试；不承诺故障仍在时自动恢复 |
| 完整 LAN/IPv6/TUN 业务 | BLOCKED | 缺设备能力或客户端 |
| 所有动态 nft 规则完全一致 | INCONCLUSIVE | 初始未取得全量运行规则快照 |

备份与校验失败先阻断修改。无快照不删除现有设置。确认需要操作者实际业务核验；不按任意外部 PID 杀进程。检测外部修改后保留快照，需协调差异，不以覆盖用户新配置获得表面成功。
