# 故障注入

实测：备份损坏后拒绝恢复且不改配置；人为使 firewall init 返回 42，部署返回 42，回滚也失败时保留现场，修复 init 后恢复成功；设备锁占用时拒绝写入；32 KiB 专用 tmpfs 内存盘写入失败时阻断修改；SSH 关闭后 watchdog 自动恢复；真实重启后启动钩子恢复。

压力测试限于 /tmp 16 MiB 文件及八轮哈希计算，实测约 4 秒，dae/dnsmasq 继续存活。不是 CPU 满载、内存耗尽或 Flash 耗尽测试。tmpfs 注入没有填满根文件系统，没有消耗 Flash 寿命。

未执行项：上传中断、Agent SIGKILL、主动停止 DNS、引擎崩溃完整业务恢复、WAN down/up、默认路由丢失、策略路由异常、真实 OOM。不得用相近的成功案例替代这些缺项。
