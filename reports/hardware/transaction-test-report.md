# 部署事务

已在设备验证：快照先于网络修改；摘要校验；完整文件恢复；设备 flock；跨引擎互斥；新 SSH 确认；确认后保留基线；外部编辑冲突保护；失败保留现场；超时及重启恢复。原生配置验证在替换前单独执行，dae 配置通过同目录临时文件和 mv 原子替换。

Python TransactionManager 的计划哈希、授权消费、状态转换、审计失败阻断、锁竞争、备份损坏和服务恢复门禁通过独立 Linux 回归，不是在本 R2S 执行。网络 Shell 并未因此自动获得完整 Python 事务引擎的全部属性，不能声称单个 Shell 调用已完成完整业务验证和自动 Commit。

外部工具在一次 apply 过程中绕过设备锁并同时写 UCI 的所有时序未穷尽；已覆盖 apply 完成后的外部文件编辑。旧部分基线和缺少 init 管理的已运行裸引擎会被拒绝，需先人工协调或纳入服务管理。
