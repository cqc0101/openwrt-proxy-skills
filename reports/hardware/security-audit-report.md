修复过程中另发现并修正：使用 stat 会在该精简固件失败；新增诊断 ID 初次未同步修复注册表。两次失败均在交付前被实际测试发现，最终回归重新执行。未把早期失败日志当作最终通过证据。

设备实际验证共享 PID 误杀、API 未授权远程可达、私有控制面修复、跨引擎锁冲突、损坏备份、外部配置编辑保护、真实写入失败。API 测试仅针对本设备短时受控端口，未触及第三方。

SSRF 私网/metadata/IPv4-mapped IPv6、请求内 DNS 固定、多跳重定向、HTTPS SNI/证书验证、路径/符号链接/锁并发和审计脱敏由独立 Linux 自动回归验证。部分解析器测试采用 mock DNS 和本机 HTTP/TLS 服务，应理解为自动化受控验证，不能等同实际 ISP 网络重绑定攻击。

SSH 首次采用 TOFU，之后固定主机密钥。未做带外指纹核验，也未在设备上执行主机密钥轮换测试。没有宣称穷尽普通用户权限提升、所有 SUID、所有系统组件漏洞或所有并发时序。
