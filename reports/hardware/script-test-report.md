# 脚本真机测试

本报告只针对本轮实际设备与当前修订代码。原始 /etc 备份、SSH 主机密钥、真实节点与订阅均留在私有工作区，不进入修复包。公开证据已脱敏；原始命令、输入和完整输出仍保存在本机私有证据目录。执行过程先完成探测与计划，再按轮次进行受控测试，未修改固件、分区或 Bootloader。

硬件台账 72 项；状态计数 {"PASS": 55, "FAIL": 3, "BLOCKED": 4, "NOT TESTED": 9, "INCONCLUSIVE": 1}。cases.json 给出每项目标、状态和证据；对应 JSON 保存命令、输出、退出码、耗时。FAIL 三项是保留的原版复现，修订复测另列。

正常参数、非法与冲突参数、重复应用/回滚、跨引擎冲突、现有配置保留、外部编辑冲突均有设备证据。没有对每一个 Python 库或主机脚本伪造设备执行结果；超长字符串、全部非法 IP/端口与节点输入的主要覆盖来自自动回归。
