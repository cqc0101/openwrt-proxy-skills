# dae 真机验证

设备原生 dae 2.1.1（linux/arm64），Linux 6.12.103，BTF 存在。原始配置 validate 通过；两种生成拓扑 main/bypass 在原生 validate 通过；错误字段被拒绝。

生成配置通过原子替换进入真实 dae 服务并执行 reload；进程存活，再次 reload 返回成功。随后由项目回滚机制恢复原始配置并重启原始服务，配置哈希与私有原始归档一致。生成节点使用本机无效测试端口，没有使用真实机场凭据证明流量；不能将进程启动或语法通过当作外网代理业务通过。

现有 dae 原始日志显示部分节点运行时解析失败，但原生 validate 不拒绝整份配置。本轮修复了诊断把此类节点问题等同于版本语法错误的行为，保留实际节点配置。物理 LAN 终端转发与热重载长连接零中断未验证，单独列为限制。
